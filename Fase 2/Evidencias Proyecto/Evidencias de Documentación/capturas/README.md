# Capturas de pantalla

Pantallazos que muestran el uso real de Jira y Confluence. Guarda cada imagen en esta carpeta con el nombre indicado y se verá automáticamente abajo.

| Archivo | Qué capturar |
| --- | --- |
| `jira-tablero-sprint.png` | Tablero del sprint activo (Sprint 2), con las columnas Por hacer, En curso, En revisión y Listo |
| `jira-backlog.png` | Vista Backlog con los sprints y sus story points |
| `jira-cronograma.png` | Cronograma (Timeline) con las épicas a lo largo de los sprints |
| `jira-historia.png` | Una historia abierta (ej. CAPDC-11) con criterios de aceptación y comentarios |
| `jira-sprint-cerrado.png` | Informe del Sprint 1 cerrado (Informes → Informe de sprint o Burndown) |
| `confluence-arbol.png` | Árbol de páginas del espacio EXPERTIA-CAP26 en la barra lateral |
| `confluence-historial.png` | Historial de versiones de una página (ej. "02.4 Diseño de Estructura Backend") |
